# MemeHub

A full-stack meme sharing platform built using:

- React
- Express.js
- MongoDB Atlas
- Cloudinary
- JWT Authentication

## Features

- User Authentication
- Meme Uploads
- Likes & Unlikes
- Comments
- User Profiles
- Delete Memes

## Tech Stack

Frontend:
- React
- React Router
- Axios

Backend:
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT

## Setup

Client:

npm install
npm run dev

Server:

npm install
npm run dev
